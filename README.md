# Tarea Python - Procesamiento de Candidatos

Este proyecto procesa un dataset de candidatos (`candidates.csv`):

- Almacena los datos en una base de datos SQLite (`candidates.db`).
- Genera reportes en CSV y gráficos en PNG.
- Simula (o envía) correos personalizados a cada candidato.

## Ejecución

```bash
python tarea_candidatos.py
